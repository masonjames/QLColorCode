## Prism Q — generate

Create one polished macOS application icon concept for QLColorCode, an open-source Quick Look syntax-highlighting utility first created in 2007, renewed for 2026. Use case: logo-brand / native macOS application icon. Concept A, 'Prism Q': a single memorable capital Q-shaped optical ring made from substantial, precisely aligned short source-code strokes in restrained coral, gold, mint and periwinkle; one unmistakable short diagonal Q tail also subtly evokes a magnifying glass, because the app gives a closer look at source code in Finder. The colorful strokes must form a coherent simple silhouette, not a scattered rainbow. A small pair of elegant code angle brackets is cut into the negative space at the center. Strong craftsmanship, thoughtful proportions, slightly tactile layered material and very subtle depth, influenced by the care of classic independent Mac utilities and the clarity of modern macOS icons. Dark midnight ink rounded-square icon tile with softly beveled edges, generous internal padding, perfectly front facing, balanced centered composition. The full icon tile fills about 82 percent of a square 1024x1024 canvas, with transparent area outside. It must remain recognizable at 32 pixels. Render exactly one icon asset, no presentation board, no mockups, no desktop, no words, no numbers, no date, no Apple logo, no Homebrew branding, no ornamental extra symbols, no lens flare, no exaggerated glass effects. This is original independent branding, not a copy of an existing app icon.

## Source Sheet — generate

Create one polished macOS application icon concept for QLColorCode, the community Quick Look source-code syntax-highlighting utility created in 2007, refreshed for 2026. Use case: logo-brand / native macOS application icon. Concept B, 'Source Sheet': a beautifully simple ivory source-document sheet with one small folded upper-right corner, standing upright on a warm off-white rounded-square icon tile. Four or five bold short horizontal code strokes on the sheet use restrained coral, amber, teal and blue, with convincing source-code indentation. The lower half of the sheet contains a single bold ink-blue Q-shaped magnifying lens with a pair of small ivory code angle brackets inside; the Q and sheet must read as one compact composition, not several overlapping app icons. Reference the long-lived Mac utility tradition through the paper document and precision, while making the geometry and spacing modern, crisp and quiet. Strong silhouette legible at 32 pixels, generous padding, soft tactile depth with restrained shadows, perfectly front-facing square composition. The full rounded-square icon tile fills about 82 percent of a square 1024x1024 canvas, with transparent area outside. Render exactly one finished icon asset, no presentation board, no mockups, no desktop, no readable words, no numbers, no date, no Apple logo, no Homebrew branding, no ornamental extra symbols, no rainbow gradient background, no exaggerated glass effects. Original independent app identity, not copying another icon.
